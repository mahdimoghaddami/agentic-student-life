# Submission checklist

- [ ] Group registered (1–2 people, including solo registration).
- [x] Separate agent modules, reflection, planning, real callable tools, memory and skills.
- [x] All nine required experiment configurations, including two model slots.
- [x] JSONL outputs, failure records, execution logs, reset instructions.
- [x] Synthetic typical/missing/preference-update fixtures and sequential episode.
- [ ] Actual StudentLife archive inspected and full codebook mapping verified.
- [ ] Real observation-derived cases selected, frozen, and documented.
- [ ] At least two real models run under identical configurations.
- [ ] All required ablations run; decision appropriateness, quality, execution, efficiency compared.
- [ ] Independent judge scores every non-null final-system message; prompt/rubric reported.
- [ ] Human independently rates >=10 messages before viewing judge results.
- [ ] Human/judge MAE computed and disagreements discussed.
- [ ] Final model retains at least two interacting agents.
- [ ] Report completed using actual metrics and generated figures.
- [ ] Presentation completed and practiced.

The unchecked items require local data, credentials, real execution, or human input.
The included code supports them but does not claim they are already completed.
