# Start here

1. Open README.md for complete commands and experimental protocol.
2. Install Python 3.10+; create a virtual environment and install this package.
3. Run the mock demo first; it needs no API key and uses synthetic data.
4. Copy .env.example to .env; enter your actual model name and credentials locally.
5. Run a live model on the synthetic cases to check the connection.
6. Inspect your StudentLife archive and complete the explicit import mapping using its EMA definitions.
7. Import real observations, create simulated profiles, and freeze evaluation cases.
8. Run all ablations, export human ratings, score with an independent judge, and generate reports/plots.
9. Complete the report/presentation outlines using actual results.

No API keys, actual participant data, or invented research scores are included.
The input mapping requires your real dataset definitions; do not treat template examples as a complete codebook.
